# Studies

`studies/` contains version-controlled study definitions and compact canonical
evidence. It is the repository location for material needed to identify a
study, interpret its evidence, and reproduce its documented analysis.

Full RunBundles, including source media and staged runtime artifacts, belong
in ignored `runs/`. Generated model and build outputs belong in ignored
`artifacts/`. Conclusions and explanatory material belong in `docs/`.
Experiment and reproducer programs belong in `tools/` or the owning source
subsystem.

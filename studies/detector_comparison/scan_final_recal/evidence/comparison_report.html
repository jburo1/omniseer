Methodology

Physical trials

Measure end-to-end behavior with each detector in the autonomy loop.

Controlled replay

Holds source video, classes, preprocessing, postprocessing, and thresholds fixed; only detector configuration changes.

The replay uses immutable source.ts, deterministic 8px repair in memory, the same corrected frame, and six resident RKNN detectors sequentially. Offline replay timing is not production runtime performance.

Closed-loop Robot Trials

These are single physical trials per configuration and are presented as end-to-end case-study evidence, not population-level estimates.
